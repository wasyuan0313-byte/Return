【東仁安居工務施工回報系統｜完整包】

三個資料夾，各自的用途：

────────────────────────────────────────────
1_上傳GitHub
────────────────────────────────────────────
  同事要用的網站。整包上傳到 GitHub repo 的根目錄。

  上傳前先做一件事：
    打開 config.js，把 Apps Script 那串「結尾是 exec 的網址」填進 apiUrl。
    還沒部署過後端的話，先看 3_後端與說明\部署說明.md。

  上傳方式：
    GitHub repo -> Add file -> Upload files
    把「這個資料夾裡面的 4 個項目」全選拖進去：
        index.html
        app.js
        config.js
        assets        <- 整個資料夾一起拖
    不要拖「1_上傳GitHub 這整個資料夾」，否則會多包一層，網站打不開。
    .nojekyll 是隱藏檔，看不到的話在檔案總管開啟「顯示隱藏項目」再一起拖。

────────────────────────────────────────────
2_平面圖區域編輯器
────────────────────────────────────────────
  你自己用的畫框工具。不用上傳，放在自己電腦就好。

  雙擊「平面圖區域編輯器.html」用瀏覽器開啟即可。
  不需要網路、不需要安裝、不需要登入。

  三個檔案要放在同一個資料夾，不要拆開。

  快速上手：
    1. 開啟平面圖 -> 選 floor-plan-04.png
    2. 載入現有 145 個標號   <- 最省力的起點
    3. 匯入數量明細（你自己的 Excel，這包裡沒有）
    4. 切到「自動偵測」點空間內部，或直接點兩下，讓它自動框
    5. 右側填房號與空間
    6. 匯出設定檔 -> floor-plan-regions.json

  做好的 floor-plan-regions.json 放進 1_上傳GitHub\assets\ 一起上傳，
  前台平面圖就會從「點小按鈕」變成「點整塊區域」。

  沒有這個檔時系統自動沿用原本的按鈕，所以可以分批做，
  中間完全不影響同事填報。

  注意：做到一半要中斷，一定要先「匯出設定檔」存起來，
       下次用「開啟既有設定」讀回來接著做。沒存就關掉等於白做。

────────────────────────────────────────────
3_後端與說明
────────────────────────────────────────────
  Code.gs              貼進 Google Apps Script 的後端程式
  部署說明.md           第一次架設的完整步驟
  使用說明_回報系統.md    日常操作：發帳號、看資料、匯出、更新
  使用說明_區域編輯器.md  畫框工具的完整說明與快捷鍵
  README.md            專案技術總覽

  .md 檔用記事本就能開，但用支援 Markdown 的軟體看排版比較好
  （VS Code、Typora，或直接把檔案拖進 Chrome 也可以）。

────────────────────────────────────────────
第一次使用的順序
────────────────────────────────────────────
  1. 讀 3_後端與說明\部署說明.md，把 Google 試算表和後端架起來
  2. 拿到網址填進 1_上傳GitHub\config.js
  3. 上傳 1_上傳GitHub 的內容到 GitHub
  4. 用管理員帳號登入，在後台建立同事帳號
  5. 有空的時候再用 2_平面圖區域編輯器 把區域畫好

────────────────────────────────────────────
重要提醒
────────────────────────────────────────────
  一、密碼建立後只顯示一次，後端只存雜湊值，無法反查。忘記就重設。
  二、網址是公開的，安全性完全靠帳密，不要用 123456 這種密碼。
  三、那份 Google 試算表不要設成「知道連結的人都可以編輯」，
      那等於繞過所有權限。
