# Google Apps Script 後端部署說明

全程免費，只需要一個 Google 帳號。照著做約 20 分鐘。

\---

## 階段一：建立試算表與後端（約 10 分鐘）

### 1\. 建立試算表

1. 開 [https://sheets.new](https://sheets.new)，建立一份新的空白試算表
2. 檔名改成例如 `東仁安居工務回報資料`
3. **這份試算表就是你的資料庫**，之後所有回報都會即時寫進來

### 2\. 貼上後端程式

1. 在試算表上方選單點 **擴充功能 → Apps Script**
2. 會開啟新分頁，裡面有一個預設的 `Code.gs`，內容是 `function myFunction() {}`
3. **全選刪掉**，把本專案 `gas/Code.gs` 的內容整份貼進去
4. 按 💾 儲存（或 Ctrl+S）

### 3\. 設定第一組管理員帳號

在剛貼上的程式裡找到 `function setup()`，把最上面三行改成你要的值：

```javascript
const ADMIN\\\_NAME = '你的姓名';
const ADMIN\\\_ACCOUNT = 'yuan';          // 你的登入帳號，3–20 碼英數字
const ADMIN\\\_PASSWORD = '自己設一組密碼';  // 至少 6 碼
```

改完再存檔一次。

### 4\. 執行 setup 建立資料表

1. 編輯器上方的函式下拉選單選 **setup**
2. 按 **▶ 執行**
3. 第一次會跳出授權：**檢閱權限 → 選你的 Google 帳號 → 進階 → 前往「專案名稱」(不安全) → 允許**
（這是因為專案沒送 Google 審查，你自己寫的腳本，這樣走是正常的）
4. 執行完回試算表看，應該多出 `users`、`reports`、`sessions`、`source`、`log` 五個分頁，`users` 裡有你這一筆

> `setup` 只跑一次。重複執行會因為帳號已存在而報錯，那是預期行為。

### 5\. 部署成網頁應用程式

1. 編輯器右上角 **部署 → 新增部署作業**
2. 左邊齒輪 ⚙ 選 **網頁應用程式**
3. 兩個關鍵設定：

   * **執行身分**：`我（你的信箱）`
   * **具有存取權的使用者**：**`任何人`**
⚠️ 一定要選「任何人」，不要選「任何具有 Google 帳戶的使用者」，選錯同事會連不上
4. 按 **部署**，再授權一次
5. 複製產生的 **網頁應用程式網址**，長得像：

```
   https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxxxxxxxxxxx/exec
   ```

## 階段二：接上前端（約 5 分鐘）

### 6\. 填入網址

打開專案根目錄的 `config.js`，把網址貼進去：

```javascript
window.DONREN\\\_CONFIG = {
  apiUrl: 'https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxxxxxxxxxxx/exec',
};
```

### 7\. 測試

直接用瀏覽器打開 `index.html`，應該看到登入畫面。用階段一設定的帳密登入。

登入後：

* 上方右邊會顯示你的姓名與帳號
* 有「後台管理中心」按鈕
* 送一筆測試回報 → 回試算表看 `reports` 分頁，資料應該立刻出現

### 8\. 放上網給同事用（GitHub Pages，免費）

1. 建一個 GitHub repo（可以設 Private，Pages 仍可公開）
2. 上傳這些檔案：

```
   index.html
   app.js
   config.js
   assets/
   ```

（`gas/`、`server.py`、`data/`、`\\\*.cmd`、`test\\\_\\\*` 不用上傳）

3. repo → **Settings → Pages → Source 選 `main` 分支 / root → Save**
4. 等 1–2 分鐘，拿到網址 `https://你的帳號.github.io/repo名稱/`
5. 把這個網址給同事

\---

## 階段三：建立同事帳號

1. 用你的管理員帳號登入
2. 進 **後台管理中心 → 帳號管理**
3. 填姓名、登入帳號、初始密碼，權限選 **僅前端填報**
4. 按「建立帳號」→ 畫面會顯示帳密一次，按「複製帳密」傳給同事

> 密碼只顯示這一次。後端只存雜湊值，無法反查。忘記就用「重設密碼」給新的。

## 日常維運

|情境|做法|
|-|-|
|看即時資料|開那份 Google 試算表，`reports` 分頁就是全部回報|
|下載成 Excel|試算表 → 檔案 → 下載 → Microsoft Excel (.xlsx)|
|依範本匯出|後台「施工回報紀錄 → 匯出 Excel」|
|同事忘記密碼|後台帳號管理 → 重設密碼|
|同事離職|後台帳號管理 → 停用（會立刻踢出登入，歷史資料保留）|
|查誰做了什麼|試算表 `log` 分頁（登入、新增、刪除、改權限都有紀錄）|
|備份|試算表 → 檔案 → 建立副本，或下載 .xlsx|

### 改了 Code.gs 之後怎麼更新

**部署 → 管理部署作業 → 右上鉛筆 ✏ → 版本選「新版本」→ 部署**

這樣網址不變。
如果你按的是「新增部署作業」，會產生**新網址**，那就要回去改 `config.js`。

## 免費額度

你們幾個人用完全用不完：

* Apps Script 一般帳號：每日執行時間 90 分鐘、URL Fetch 20,000 次
* 試算表上限：1,000 萬個儲存格（`reports` 一筆 14 格 → 約 70 萬筆回報）
* 沒有閒置暫停，不用養機器

## 常見狀況

**登入按下去沒反應／顯示「後端回應格式錯誤」**
部署權限沒設成「任何人」。回去 管理部署作業 → ✏ → 改成任何人 → 部署。

**顯示「尚未設定後端網址」**
`config.js` 的 `apiUrl` 還是空的，或網址結尾不是 `/exec`。

**送出很慢（2–3 秒）**
正常。Apps Script 每次呼叫都要喚醒一次，加上寫入上鎖。人少不影響。

**同事說「登入逾時」**
登入有效 12 小時，超過要重登。要改的話調整 `Code.gs` 的 `SESSION\\\_HOURS`。

## 安全性說明（請看一次）

* 密碼用 1000 次迭代 HMAC-SHA256 + 每人獨立 salt 雜湊後才存，試算表裡看不到明碼
* 登入權杖存在後端 `sessions` 分頁，逾時或帳號停用即失效
* **填表人姓名由後端依登入帳號寫入**，前端改不了，同事無法冒名
* 刪除回報、匯入數量明細、管理帳號都只有 `admin` 權限能做，後端會再驗一次
* 已移除舊版的 `X-Manager-Identifier` 前端寫死主管身分，以及寫在程式碼裡的 `yuan0914` 明碼識別

仍要注意：

* 網址是公開的，安全性完全靠帳密。**不要用 123456 這種密碼**
* 試算表本身不要按「共用 → 知道連結的人都可以編輯」，那等於繞過所有權限
