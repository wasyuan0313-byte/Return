# 平面圖區域編輯器｜使用說明

把平面圖上的每個空間框起來、命名，做出一份設定檔，讓同事在前台**點整塊區域**就能選取，不必再瞄準小按鈕。

- 雙擊 `平面圖區域編輯器.html` 用瀏覽器開啟即可
- 不需要網路、不需要安裝、不需要登入，全部在這台電腦跑
- 建議用 Chrome 或 Edge

---

## 一、五分鐘上手

| 步驟 | 動作 | 說明 |
|---|---|---|
| 1 | **開啟平面圖** | 選 `floor-plan-04.png` |
| 2 | **載入現有 145 個標號** | 把系統裡已有的標號位置直接變成可拉的框，房號空間都填好了 |
| 3 | **匯入數量明細** | 選你的數量明細 Excel，右側「檢核」才會開始幫你抓錯 |
| 4 | 逐一調整每個框 | 見下方「四種畫框方式」 |
| 5 | **匯出設定檔** | 存出 `floor-plan-regions.json` |

> 步驟 2 是最省力的起點。145 個框的房號與空間都預先填好，你只要把框拉到實際範圍，不用從零畫。

---

## 二、四種畫框方式

### ⌖ 自動偵測（最快，快捷鍵 `A`）

點空間內部的空白處，工具會沿著牆線自動框出輪廓。

也可以在**選取模式下對著空間點兩下**，效果相同。

工具列的**容差**決定顏色擴散的範圍：

| 狀況 | 怎麼調 |
|---|---|
| 只框到一小塊，被家具線擋住 | 容差**調大**（例如 30 → 50） |
| 顏色擴散到整張圖 | 容差**調小**（例如 30 → 15）。通常是牆線有缺口 |
| 怎麼調都不對 | 改用畫矩形或多邊形 |

> 自動偵測只是**初步框選**，抓完一定要自己檢查、拉節點修正。牆線斷掉、家具太密的地方本來就抓不準。

### ▭ 畫矩形（快捷鍵 `R`）

按住滑鼠拖曳。方正的房間用這個最快。

### ⬠ 畫多邊形（快捷鍵 `P`）

連續點擊放節點，**雙擊**或按 `Enter` 收尾，`Esc` 取消。L 形、不規則的空間用這個。

### ▖ 選取與修改（快捷鍵 `V`）

| 想做的事 | 操作 |
|---|---|
| 移動整塊 | 在框內按住拖曳 |
| 改矩形大小 | 拖四個角的白色方塊 |
| 移動多邊形節點 | 拖白色方塊 |
| **增加節點** | 拖邊線中間的**空心圓點**，會就地插入一個節點並直接進入拖曳 |
| **刪除節點** | 按住 `Alt` 點該節點（至少保留 3 個） |
| 刪除整塊 | 選取後按 `Delete`，或右上角「刪除」 |

## 三、命名與自動抓資料

選到一個框，右側填**房號**（A19）與**空間**（廁所），兩欄都有下拉建議，不必手打。

代碼會依空間名稱自動判定：

| 空間名稱含有 | 代碼 |
|---|---|
| 廁所 | `B` |
| 廚房 | `K` |
| 陽台 | `Y` |
| 室內／臥室／主臥／客廳 | `I` |
| 走廊 | `廊` |

框的顏色跟著代碼走 —— 藍＝室內、青＝廁所、橘＝廚房、綠＝陽台。**一眼就看得出有沒有標錯**。

填完後右側立刻顯示這個區域在數量明細裡的資料：

```
✓ 對應到 12 筆數量明細
  涵蓋樓層   4、5、6、7、8、9F
  單層面積   3.2 ㎡
  施作位置   地坪、牆面
```

打錯就是紅字：**「⚠ 數量明細裡找不到 A19 的『廁所』」**。

## 四、文字位置

- 矩形：文字固定在正中央
- 多邊形：文字自動放在**形狀內部最寬敞的位置**。L 形、U 形的凹角處不會被標到框外
- 想自己決定位置：**直接拖曳圖上的文字**
- 拖過的文字周圍會出現虛線圈，代表是自訂位置
- 要還原：右側「文字位置 → 重設為自動置中」

---

## 五、右側「檢核」在幫你看什麼

| 項目 | 意思 |
|---|---|
| 區域總數 | 目前畫了幾個框 |
| **未命名** | 還沒填房號或空間。點一下會跳到那個框 |
| 房號＋空間重複 | 同房號的同一種空間被框了兩次 |
| **明細查無對應** | 房號或空間打錯，數量明細裡找不到。點一下會跳過去 |
| **明細有、尚未框選** | 明細裡有這個空間，但你還沒框。**用這項確認有沒有漏掉** |

最後兩項要先匯入數量明細才會出現。

## 六、全部快捷鍵

| 鍵 | 功能 |
|---|---|
| `V` | 選取 |
| `R` | 畫矩形 |
| `P` | 畫多邊形 |
| `A` | 自動偵測 |
| `H` 或按住空白鍵 | 平移畫面 |
| 滾輪 | 縮放 |
| `Ctrl` + `Z` | 復原（可連續 60 步） |
| `Delete` | 刪除選取的區域 |
| `Alt` + 點節點 | 刪除該節點 |
| `Enter` | 完成多邊形 |
| `Esc` | 取消目前動作／取消選取 |

## 七、做到一半要中斷

先按 **匯出設定檔**，把 `floor-plan-regions.json` 存起來帶走。
下次用 **開啟既有設定** 讀回來就能接著做。

**沒存就關掉等於白做**，工具不會自動保存。

---

## 八、做完之後怎麼上線

1. 把 `floor-plan-regions.json` 放進網站的 `assets/` 資料夾
2. 跟其他檔案一起上傳到 GitHub
3. 前台的平面圖就會從「點小按鈕」變成「點整塊區域」

**沒有這個檔的時候，系統會自動沿用原本的 145 個按鈕。**
所以你可以分批做、慢慢完善，中間完全不影響同事填報。

---

## 九、常見狀況

**自動偵測整張圖都變成一塊**
容差太大，或那個房間的牆線有缺口。把容差調小，或改用多邊形手動畫。

**匯入數量明細時說找不到 xlsx.full.min.js**
`xlsx.full.min.js` 要和這個 HTML 放在同一個資料夾（或它的 `assets` 子資料夾）內。

**匯入數量明細時說找不到「數量明細表」**
Excel 裡的工作表名稱必須正好是「數量明細表」。

**匯出時說還有幾個沒填房號**
沒填房號或空間的框**不會被匯出**。可以先匯出已完成的部分，之後再補。

**畫面卡卡的**
區域超過 300 個時縮放會變慢。這是正常的，不影響匯出結果。
