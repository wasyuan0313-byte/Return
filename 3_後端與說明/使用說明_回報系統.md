# 東仁安居工務施工回報系統｜使用說明

同事在手機或電腦填報，資料即時寫進你的 Google 試算表，你隨時打開就看得到、隨時下載成 Excel。

---

## 一、兩種身分

| 身分 | 帳號權限 | 看得到什麼 |
|---|---|---|
| **你**（管理員） | `admin` | 前端填報 ＋ 後台：全部回報、刪除回報、匯入數量明細、匯出 Excel、管理帳號 |
| **同事** | `front` | 只有前端填報，只看得到自己送出的紀錄 |

同事**完全看不到後台入口** —— 按鈕與模式切換列都不會出現。就算用開發者工具硬把按鈕叫出來也進不去，後端還會再驗一次，且只會回傳他自己的資料。

---

## 二、同事怎麼用（前端填報）

1. 打開你給的網址
2. 輸入你配發的**帳號與密碼**
3. 依序選 **施工日期 → 樓層 → 工項**
4. 在平面圖上點選施作的空間
5. 填 **出工人數**（以 0.5 工為單位）
6. 填 **材料實際用量**（選填，不填就留白）
7. 填現場備註 → **檢查並送出回報** → 確認內容 → **確實送出**

> **填表人姓名不用填、也改不了**，系統一律用登入帳號的姓名。這樣你才知道每筆資料是誰填的，同事也無法冒名。

### 手機上的平面圖

平面圖右上角有 **−** / **＋** 縮放鈕。

手機預設是「看得見全貌」，所以標號會很小：

1. 先用預設倍率找到你要的房號位置
2. 按 **＋** 放大到看得清楚
3. 再點選空間

轉向手機畫面會自動重算，不用重新整理。

---

## 三、你怎麼用（後台管理）

登入後右上角會出現「⚙ 後台管理中心」。

### 施工回報紀錄

- 上方搜尋框可查日期、填表人、房號
- **匯出 Excel**：依內建範本產生「實際用量回饋表」，另附施工統計頁
- 每筆最右邊有刪除鈕（只有管理員能刪）

### Excel 數量資料

匯入含有「**數量明細表**」工作表的材料數量檔。匯入後前台填報時才會帶出正確的材料品項。

### 帳號管理

| 想做的事 | 怎麼做 |
|---|---|
| 新增同事 | 填姓名、登入帳號、初始密碼，權限選「僅前端填報」→ 建立帳號 |
| 給同事帳密 | 建立後畫面會顯示一次，按「複製帳密」傳給他 |
| 同事忘記密碼 | 「重設密碼」給一組新的 |
| 同事離職 | 「停用」。他會**立刻**被踢出登入，歷史資料保留 |
| 讓同事也能看後台 | 勾選「後台管理權限」 |

> **密碼只顯示這一次。** 後端只保存雜湊值，無法反查。忘記就重設。

### 修改自己的密碼

點右上角自己的名字。

---

## 四、資料在哪裡

全部在那份 Google 試算表：

| 分頁 | 內容 |
|---|---|
| `reports` | **所有施工回報**，人類可讀，就是你要的資料 |
| `users` | 帳號與密碼雜湊（看不到明碼） |
| `sessions` | 登入工作階段，會自動清理 |
| `source` | 數量明細（程式用，不必看） |
| `log` | 稽核紀錄：誰在何時登入、新增、刪除、改權限 |

**下載成 Excel**：試算表 → 檔案 → 下載 → Microsoft Excel (.xlsx)
**備份**：試算表 → 檔案 → 建立副本

## 五、平面圖區域設定（選用）

如果你用「平面圖區域編輯器」做了 `floor-plan-regions.json`，把它放進 `assets/` 一起上傳，前台就會從「點小按鈕」變成「**點整塊區域**」。

沒有這個檔時系統自動沿用原本的 145 個按鈕，所以可以分批做，中間不影響同事填報。

詳見 `使用說明_區域編輯器.md`。

## 六、部署與更新

第一次架設請看 `gas/部署說明.md`。以下是日常會遇到的：

### 改了前端（index.html / app.js）

重新上傳到 GitHub 覆蓋即可，同事重新整理就是新版。

### 改了後端（gas/Code.gs）

**部署 → 管理部署作業 → 右上鉛筆 ✏ → 版本選「新版本」→ 部署**

這樣**網址不變**，`config.js` 不用改。
如果按成「新增部署作業」會產生**新網址**，那就要改 `config.js` 並重新上傳。

### 要上傳到 GitHub 的檔案

```
index.html
app.js
config.js
.nojekyll
assets/floor-plan-04.png        平面圖
assets/xlsx.full.min.js         Excel 元件
assets/report-template.xlsx     匯出範本
assets/floor-plan-regions.json  區域設定（做好了才有）
```

`gas/`、`region-editor.html`、`test_*`、`使用說明_*.md` 都**不用**上傳。

> 用網頁拖曳上傳時 `assets/` 常被攤平成散檔。程式兩種結構都吃得下：先找 `assets/檔名`，找不到自動改找根目錄。

## 七、常見狀況

**同事說登入沒反應／後端回應格式錯誤**
Apps Script 部署權限沒設成「任何人」。回 管理部署作業 → ✏ → 改成任何人 → 部署。

**畫面顯示「尚未設定後端網址」**
`config.js` 的 `apiUrl` 是空的，或網址結尾不是 `exec`。

**平面圖一片空白**
`floor-plan-04.png` 沒上傳。畫面下方會直接寫出缺哪個檔。

**匯出 Excel 失敗**
`xlsx.full.min.js` 或 `report-template.xlsx` 沒上傳。

**同事說登入逾時**
登入有效 12 小時。要調整就改 `gas/Code.gs` 的 `SESSION_HOURS`，改完記得重新部署。

**送出要等 2–3 秒**
正常。Apps Script 每次呼叫都要喚醒一次，加上寫入上鎖。人少不影響。

## 八、安全性

已經處理好的：

- 密碼用 1000 次迭代 HMAC-SHA256 ＋ 每人獨立 salt 雜湊後才存，試算表裡看不到明碼
- 登入權杖存在後端，逾時或帳號停用即失效
- **填表人姓名由後端依登入帳號寫入**，前端改不了
- 刪除回報、匯入明細、管理帳號都只有管理員能做，後端會再驗一次
- 未登入與 `front` 帳號完全看不到後台入口

還是要你注意的：

- 網址是公開的，安全性完全靠帳密 —— **不要用 123456 這種密碼**
- 那份試算表**不要**設成「知道連結的人都可以編輯」，那等於繞過所有權限
- 如果 GitHub repo 設成 Public，`config.js` 裡的網址等於公開，密碼強度更重要
