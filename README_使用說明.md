# 東仁安居工務施工回報系統

## 啟動與分享

1. 雙擊 `啟動工務回報系統.cmd`，並保持視窗開啟。
2. 本機使用 `http://127.0.0.1:8765/`。
3. 同一個 Wi-Fi／區域網路的手機或電腦，使用 `http://本機IPv4位址:8765/`。
4. Windows 第一次詢問防火牆時，只允許「私人網路」。

可在 PowerShell 執行 `ipconfig`，於目前使用的網路介面尋找「IPv4 位址」。例如本機 IPv4 是 `192.168.1.20`，其他裝置就開啟 `http://192.168.1.20:8765/`。

請勿直接把 8765 連接埠公開到網際網路。若要讓工地外的人填報，應改用具 HTTPS 與備份機制的正式主機或 VPN。

## 第一次設定

1. 進入「主管權限設定」，輸入主管帳號 `yuan0914`。
2. 建立使用者姓名，選擇「後台管理」或「前端登陸」。
3. 系統會依序核發 `UG015001`～`UG015999`，裝置編號與末三碼使用同一流水號（例如裝置 01 對應末三碼 001）。
4. 將末三碼交給使用者；同一瀏覽器、同一網址第一次輸入後會記住登入，下次開啟會自動帶入。
5. 後台管理者匯入「防水、磁磚、隔音墊材料數量.xlsx」的數量明細。

只有統一權限主管可以新增、停用或重新啟用權限碼，也可在帳號停用期間調整後台登入權限。後台管理者可以填報、檢視回報、匯入數量資料與匯出 Excel；前端使用者只能填報。

## 前端填報

選好日期、樓層與工項後，直接在平面圖點選完整的房號／空間標號，例如「A02 廁所」。選中的空間會以藍色亮起，並列在平面圖下方；再次點選或按標籤上的 × 即可取消。平面圖可水平、垂直捲動，以保留所有標號的清晰度。

## 資料與備份

集中資料存放在 `data/app.db`。備份時先關閉啟動視窗，再複製整個 `data` 資料夾；請勿只複製網頁檔案。

Excel 匯出會保留「實際用量回饋表」A:X 格式，並新增「施工統計補充」工作表，保存施作天數、總出工人數、施作面積與空間名稱。
